Responsive CSS Cheat Sheet

Master the four pillars of modern responsive web development. Built using CSS Grid with adaptive multi-column desktop layout shifting into stacked rows below 700px.

🎨
Module 01

Filters

CSS filters can modify the appearance of images, elements, and graphics by executing visual operations like blurring, desaturating, shifting hues, and contrast adjustments in GPU memory.

Example CSS
/* Apply monochrome conversion */
img {
    filter: grayscale(100%);
}

/* Chained visual adjustments */
.photo-enhanced {
    filter: contrast(130%) brightness(110%);
}
📐
Module 02

Media Queries

Media queries allow styles to change based on screen size, device orientation, pixel density, and user preferences, enabling customized adaptive stylesheets.

Example CSS
/* Mobile breakpoint below 700px */
@media (max-width: 700px) {
    .container {
        flex-direction: column;
        padding: 1rem;
    }
}
🌐
Module 03

Responsive Design

Responsive design crafts fluid, device-agnostic user interfaces using proportional grid tracks, flexible percentage sizing, and relative box constraints that eliminate horizontal scrolling.

Example CSS
/* Auto-fitting responsive grid */
.grid-layout {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(280px, 1fr));
    gap: 1.5rem;
}
✍
Module 04

Typography

Fluid typography dynamically computes font sizes between safe minimum and maximum boundaries based on viewport width, preserving visual hierarchy without jumpy breakpoints.

Example CSS
/* Clamped fluid typography */
h1 {
    font-size: clamp(1.75rem, 4vw, 3rem);
    line-height: 1.2;
}

p {
    font-size: clamp(1rem, 1.5vw, 1.25rem);
}
