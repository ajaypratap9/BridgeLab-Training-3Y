Things I Learned This Week

Published on: August 17, 2026

This week was intensely focused on web development fundamentals and understanding semantic HTML tags. Instead of relying solely on generic container divs, learning semantic elements like header, nav, main, article, section, aside, and footer creates a much cleaner, accessible, and structured webpage.

"Clean structure and meaningful markup are the foundation of any great web application."

I also spent time practicing recursion in Java and understanding how memory stacks work during recursive function calls. It was challenging at first, but visual tree diagrams made it much easier to grasp.
