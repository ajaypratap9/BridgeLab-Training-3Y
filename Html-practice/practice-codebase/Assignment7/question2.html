Height and Width Practice

Three boxes with different dimensions built using different CSS units (px, %, vh, em), plus min-height, max-width and overflow.

Box 1 - px + min-height

width: 240px

min-height: 200px

This box uses fixed pixel (px) width. Its minimum height is 200px, but it can grow taller on its own if the content needs more space.

Box 2 - % width + overflow

width: 40%

overflow: auto

This box's width is 40% of the parent container. Plenty of text is placed inside so you can see how the overflow: auto property scrolls the overflowing content instead of breaking the layout. Box 3 - vh + em

height: 32vh

max-width: 55em

This box is 32 units of viewport height (32% of the screen height). Font sizes and the maximum width are written in em, which scale relative to the base font size.
