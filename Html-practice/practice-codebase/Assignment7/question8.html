The CSS Box Model

Every element on a web page is a box made of four layers: content, padding, border and margin. The demonstration below shows each layer with a different color.

Margin (yellow area)

Border (orange ring)

Padding (light green)

Content

Inside a box

Content
The actual text or image.
Padding
Space between the content and the border.
Border
The element's edge — a visible/colored line.
Margin
Space outside the border separating the box from its neighbors.

box-sizing: the size surprise

Default (content-box)

Same width / height is set below, but padding and border are added ON TOP of that size.

200px wide declared

Measured total ≈ 260px wide (200 + padding + border).

box-sizing: border-box

Padding and border are included inside the declared size, so the box stays exactly 200px.

200px wide declared

Measured total = exactly 200px wide.
