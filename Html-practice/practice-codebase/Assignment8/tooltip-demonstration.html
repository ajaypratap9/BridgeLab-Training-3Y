How CSS-Only Tooltips Function

The parent .tooltip-container establishes a positioning context with position: relative;. The tooltip child is taken out of normal document flow with position: absolute; and positioned above the anchor. By setting default opacity: 0; and switching to opacity: 1; on :hover, pure CSS achieves a fluid tooltip with zero JavaScript overhead.
