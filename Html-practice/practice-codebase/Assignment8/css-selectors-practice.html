The 8 Essential CSS Selectors

Explore how browsers parse Element, Class, ID, Attribute, Child, Adjacent Sibling, General Sibling, and Descendant selectors to apply granular styling rules.

01. Element Selector

Targeting Base HTML Tags

This paragraph is styled by an element selector. Element selectors directly match any HTML node sharing the tag name across the document.

p { color: #334155; }
02. Class Selector

Reusable Style Abstractions

Standard paragraph without special classes.

This paragraph has the class .highlight. Class selectors begin with a period and can be applied across multiple elements.

.highlight { background: #fef08a; color: #854d0e; }
03. ID Selector

Unique Document Identity

This element is styled via #special. ID selectors begin with a hash and should match only a single unique element per HTML document.

#special { color: #dc2626; font-weight: 700; }
04. Attribute Selector

Attribute-Specific Targeting

Inspects HTML element attributes and values:

input[type="email"] { border-color: #2563eb; }
05. Child Combinator (>)

Direct Children Only

Direct child paragraph (<div class="parent"> > <p>) — Styled Green.

Nested grandchild paragraph inside a wrapper — NOT styled by direct child combinator.

.parent > p { color: #16a34a; font-weight: 700; }
06. Adjacent Sibling (+)

Immediately Following Sibling

Adjacent Anchor Heading

This paragraph immediately follows the heading (h2 + p) — Top margin eliminated and emphasized in indigo.

Second sibling paragraph — NOT adjacent to the h2 element.

h2.adjacent-heading + p { color: #4338ca; margin-top: 0; }
07. General Sibling (~)

All Subsequent Siblings

General Anchor Heading

First subsequent sibling paragraph.

Second subsequent sibling paragraph.

All paragraphs following .general-heading share muted slate styling.

h2.general-heading ~ p { color: #64748b; font-style: italic; }
08. Descendant Selector (Space)

Any Depth Descendants

Deeply nested paragraph inside .card p. Matches regardless of nesting depth within the parent container.

.card p { line-height: 1.8; color: #0284c7; }
