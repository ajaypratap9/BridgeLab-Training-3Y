Standard Action Tiers

Click, hover, focus, or tab through each button to inspect states.

:hover State

Lifts the button by -2px, enriches box-shadow, and smoothly interpolates background color via transitions.

:active State

Depresses the button with transform: translateY(1px);, giving tactile mechanical tactile response.

:focus State

Displays an accessible outline: 3px solid #93c5fd; for keyboard tab navigation compliant with WCAG.

:disabled State

Enforces opacity: 0.5; cursor: not-allowed; and prevents hover elevation or transform gestures.
