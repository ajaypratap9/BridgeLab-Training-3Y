content-box vs. border-box

Both comparison boxes below share the exact same declared width: 320px;, padding: 25px;, and border: 6px solid;. Observe how box-sizing fundamentally alters their final rendered physical footprints.

Default: content-box

Box 1 (content-box)

Declared Width: 320px
Padding (Left + Right): 25px + 25px = 50px
Border (Left + Right): 6px + 6px = 12px
Total Rendered Width: 320 + 50 + 12 = 382px!

Notice how padding and border expand OUTWARD, swelling the box 62px beyond the declared width!

Modern: border-box

Box 2 (border-box)

Declared Width: 320px
Padding (Left + Right): 25px + 25px = 50px
Border (Left + Right): 6px + 6px = 12px
Total Rendered Width: Strictly 320px!

Padding and borders are absorbed INWARD into the declared width. Total footprint never exceeds 320px.

Mathematical Mechanics of the CSS Box Model

What is content-box?

In the browser's default content-box model, the width property defines only the width of the raw content area. Any subsequent padding and borders are added on top of the declared width:

Total Width = width + padding-left + padding-right + border-left + border-right

What is border-box?

Under box-sizing: border-box;, the declared width defines the total exterior dimension including borders and padding. The content area automatically shrinks inward to fit:

Total Width = declared width (padding & border accommodated internally)
