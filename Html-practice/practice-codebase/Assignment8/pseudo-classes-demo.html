Understanding CSS Pseudo-Classes

CSS pseudo-classes target elements based on user interaction states, document history, and DOM tree positions. Interact with each panel below to observe state transitions.

:hover

Pointer Hover

Hover Over Me

:hover applies styles when the user positions the pointing device (mouse cursor) over an element without activating it.

.demo-link:hover { color: #fff; background: #2563eb; }
:focus

Keyboard & Click Focus

:focus applies styles when an element receives keyboard focus or user selection, essential for accessible navigation.

.demo-input:focus { outline: 3px solid #93c5fd; }
:active

Activation State

:active applies styles during the active activation phase between the mouse button press and its release.

.demo-button:active { transform: scale(0.95); }
:nth-child()

Structural Ordering

  • Item 1: Default Child
  • Item 2: Highlighted (:nth-child(2))
  • Item 3: Default Child
  • Item 4: Highlighted (:nth-child(4))

:nth-child(an+b) targets elements based on their numeric ordinal index among siblings in the parent container.

.demo-list li:nth-child(2) { background: #dbeafe; }

Why Pseudo-Classes Matter in UI Engineering

Pseudo-classes allow web designers to build reactive, accessible, and intuitive user interfaces purely using CSS declarative stylesheets without heavy JavaScript event handlers. Combining stateful pseudo-classes with CSS transforms and transitions provides instantaneous feedback for tactile user interactions.
