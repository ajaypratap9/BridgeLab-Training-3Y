Keyframe Timing & Performance Note

By centering animated components with Flexbox rather than fragile absolute coordinate positioning, responsive bounds are preserved. Animating transform properties (translate, scale) rather than margin/top triggers GPU compositing passes, guaranteeing smooth 60fps frame rates.
